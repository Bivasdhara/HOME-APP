# 📱 Smart Home Android Controller App (স্মার্ট হোম অ্যান্ড্রয়েড অ্যাপ)

এই অ্যান্ড্রয়েড অ্যাপ্লিকেশনটি তৈরি করা হয়েছে **ESP8266 Smart Home Automation** সিস্টেমকে যেকোনো অ্যান্ড্রয়েড মোবাইল থেকে সহজে, দ্রুত ও প্রিমিয়াম ডিজাইনে নিয়ন্ত্রণ করার জন্য।

---

## ✨ অ্যাপের মূল বৈশিষ্ট্যসমূহ (Features)

1. **🌤️ রিয়েল-টাইম ক্লাইমেট ও গুগল ওয়েদার স্টাইল "Feels Like":**
   - DHT11 সেন্সরের বাস্তব তাপমাত্রা (°C) ও আর্দ্রতা (%) লাইভ ডিসপ্লে।
   - NOAA Heat Index ফর্মুলায় তৈরি **অনুভূত তাপমাত্রা (Feels Like °C)**।
   - আবহাওয়া স্ট্যাটাস ব্যাজ (স্বাভাবিক আবহাওয়া, আরামদায়ক, উষ্ণ ও আর্দ্র, তাপদাহ সতর্কতা)।

2. **🌀 সার্ভো মোটর ফ্যান স্পিড (০°-২৭০° ওয়াইড রেঞ্জ):**
   - প্রিমিয়াম সাইবার নিয়ন স্লাইডিং বার (0% থেকে 100%)।
   - সুনির্দিষ্ট নিয়ন্ত্রণের জন্য **`[−]` এবং `[+]` ৫% স্টেপার বাটন**।
   - রিয়েল-টাইম সার্ভো এঙ্গেল রিডআউট (যেমন: `০°-২৭০°` রেঞ্জ)।

3. **❄️ স্মার্ট এসি (অটোমেটিক ক্লাইমেট কন্ট্রোল):**
   - **`🖐️ ম্যানুয়াল`** এবং **`❄️ অটো (স্মার্ট এসি)`** সুইচ মোড।
   - অটো মোডে তাপমাত্রা অনুযায়ী ফ্যানের গতি স্বয়ংক্রিয়ভাবে পরিবর্তিত হয়।
   - **ম্যানুয়াল থেকে অটোতে ফেরার টাইমার:** ১৫ মিনিট, ৩০ মিনিট, ১ ঘন্টা বা কাস্টম টাইমার।

4. **💡 ৪টি রিলের পূর্ণ নিয়ন্ত্রণ ও কাউন্টডাউন টাইমার:**
   - রিলে ১ (লাইট), রিলে ২ (ফ্যান পাওয়ার), রিলে ৩ (সকেট), রিলে ৪ (ল্যাম্প)।
   - প্রতিটি রিলের জন্য স্বতন্ত্র **কাউন্টডাউন টাইমার ডায়লগ** (নির্ধারিত সময় পর স্বয়ংক্রিয়ভাবে অন বা অফ)।

5. **⚡ পাওয়ার-কাট মেমোরি সিঙ্ক ও হ্যাপটিক ফিডব্যাক:**
   - প্রতিবার বাটন চাপলে বা স্লাইড করলে মৃদু কম্পন (Haptic Vibrate)।
   - ডিভাইস স্ট্যাটাস প্রতি ১.৫ সেকেন্ডে স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে রিফ্রেশ হয়।

6. **🌐 সহজ সংযোগ ও ফলব্যাক:**
   - ডিফল্ট ডোমেন: `http://smarthome.local`
   - হটস্পট মোড ফলব্যাক: `http://192.168.4.1`
   - সেটিংসে গিয়ে যেকোনো কাস্টম আইপি (যেমন রাউটারের অ্যাসাইন করা আইপি `192.168.0.x`) দেওয়ার সুবিধা।

## 🛠️ অ্যান্ড্রয়েড স্টুডিওতে অ্যাপটি কীভাবে চালাবেন ও APK তৈরি করবেন?

### ধাপ ১: অ্যান্ড্রয়েড স্টুডিওতে প্রজেক্ট ওপেন করুন
1. আপনার কম্পিউটারে **Android Studio** চালু করুন।
2. **Open** বা **File > Open** এ ক্লিক করুন।
3. নিচের ফোল্ডার পাথটি সিলেক্ট করুন:
   ```
   C:\Users\bivas\.gemini\antigravity\scratch\SmartHomeAndroidApp
   ```
4. অ্যান্ড্রয়েড স্টুডিও স্বয়ংক্রিয়ভাবে Gradle সিঙ্ক সম্পন্ন করবে (১-২ মিনিট সময় লাগতে পারে)।

### ধাপ ২: মোবাইল ফোনে সরাসরি রান করুন
1. আপনার অ্যান্ড্রয়েড মোবাইলের **Settings > Developer Options** এ গিয়ে **USB Debugging** চালু করুন।
2. ইউএসবি ক্যাবল দিয়ে ফোনটি কম্পিউটারের সাথে কানেক্ট করুন।
3. অ্যান্ড্রয়েড স্টুডিওর উপরের টুলবারে আপনার ফোনের মডেল দেখা যাবে।
4. সবুজ রঙের **Run (▶)** বাটনে ক্লিক করুন। সাথে সাথে অ্যাপটি ফোনে ইনস্টল হয়ে চালু হবে!

### ধাপ ৩: সরাসরি ইনস্টলযোগ্য `.apk` ফাইল তৈরি করুন
1. অ্যান্ড্রয়েড স্টুডিওর মেনু থেকে যান:
   ```
   Build > Build Bundle(s) / APK(s) > Build APK(s)
   ```
2. বিল্ড শেষ হলে নিচে নোটিফিকেশন আসবে: **"APK(s) generated successfully"**।
3. **`locate`** লিংকে ক্লিক করলে আপনি তৈরি হওয়া `app-debug.apk` ফাইলটি পেয়ে যাবেন।
4. এই ফাইলটি আপনার ফোনে ব্লুটুথ, হোয়াটসঅ্যাপ বা ক্যাবল দিয়ে পাঠিয়ে সরাসরি ইনস্টল করে নিতে পারবেন।

## 📱 তাৎক্ষণিক অল্টারনেটিভ (বিনা ইনস্টলেশনে ফুল-স্ক্রিন PWA অ্যাপ)

আপনি যদি এখনই কোনো কিছু কম্পাইল বা বিল্ড না করেই আপনার মোবাইলে অ্যাপের মতো হোম স্ক্রিনে শর্টকাট রাখতে চান:
1. আপনার মোবাইলের ওয়াইফাই দিয়ে স্মার্ট হোমের সাথে যুক্ত হোন (অথবা একই রাউটারের ওয়াইফাইতে থাকুন)।
2. মোবাইলের Chrome ব্রাউজারে গিয়ে লিখুন:
   `http://smarthome.local` অথবা `http://192.168.4.1`
3. ক্রোম ব্রাউজারের উপরে ডানদিকের তিনটি ডট (⋮) মেনুতে চাপ দিন।
4. **"Install app"** অথবা **"Add to Home screen"** (হোম স্ক্রিনে যুক্ত করুন) চাপুন।
5. আপনার মোবাইলের হোম স্ক্রিনে একটি সুন্দর অ্যাপ আইকন চলে আসবে এবং এটি পুরো অ্যান্ড্রয়েড অ্যাপের মতো ফুল-স্ক্রিনে ওপেন হবে!
